RP2350 CD-RW Emulator - demo disc
=================================

If you can read this file, the host has mounted the virtual CD-ROM
and is reading 2048-byte user sectors from the ISO image.

Try copying this file to your desktop, then eject and reload the disc.

For a writable CD-RW, use tools/cdrw.py to create a .CDR image and burn
an ISO with ImgBurn or wodim.
